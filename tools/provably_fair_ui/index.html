Provably-Fair Verifier

Paste your server seed, client seed, nonce and the game you played, then click Verify. The result is computed entirely in your browser — nothing is uploaded.

How it works

HMAC_SHA256(server_seed, client_seed + ":" + nonce + ":" + cursor)
 
Bytes are read 4 at a time; values above the largest multiple of n
that fits in 2^32 are rejected (no modulo bias).
